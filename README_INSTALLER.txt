ABOUT THIS APPLICATION
----------------------
STX1 System Monitor is a comprehensive Windows system monitoring and
optimization tool that helps you:

  * Monitor CPU, GPU, memory, disk, network, battery and temperatures in
    real time
  * Clean temporary files, browser cache and registry entries, with a real
    registry backup taken before anything is changed
  * Manage the programs that run at startup, using the same mechanism Task
    Manager uses, so every change is reversible
  * Manage running processes and installed programs
  * Map your network, analyze WiFi, and scan for Bluetooth devices
  * Securely wipe files, with the last pass read back and verified
  * Back up and restore your files, with optional authenticated encryption
  * Game Mode, which lowers background apps below your game rather than
    closing them
  * PDF, image and file tools

SYSTEM REQUIREMENTS
-------------------
  * Windows 10 version 2004 (build 19041) or later
  * Windows 11 (any version)
  * 64-bit processor (x64)
  * 4 GB RAM minimum (8 GB recommended)
  * 300 MB available disk space

INSTALLATION NOTES
------------------
  * Administrator privileges are required for installation
  * Some features require administrator privileges to function, including
    hardware temperature sensors, HKLM startup entries, and cleaning the
    Windows temp folder
  * The application is self-contained: it carries the .NET 8 and Windows App
    SDK runtimes with it, so there is nothing to install separately
  * Some antivirus software flags system monitoring tools that read hardware
    sensors. This is a false positive.
